### 自己注册的坑

- 需要对应地区的地址信息（美区要美国地址，随便填可能触发风控）
- 部分区域要求当地支付方式才能完成验证
- 注册后如果长期不用，可能被回收
- 好处是资料完全自己掌握，最安心

### 买独享号的坑

- 便宜到离谱的（几元）通常是批量注册的随机后缀新号，没有密保，你改不了密码
- 正规的会标明注册年份、邮箱后缀类型、是否可转区、是否带密保
- **判定标准**：交付后你能不能改密码、能不能绑自己的备用邮箱。都不能的，本质还是共享号

### 用共享号的坑

- 只能登 App Store，不能登 iCloud
- 不能绑手机号、不能开双重认证、不能内购
- 密码定期轮换，你手上的是旧密码时会提示「密码错误」
- 上一个人没退出，账号就会被锁
